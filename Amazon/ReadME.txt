
# Amazon Dataset Instances

This folder contains the instances derived from the Amazon Last Mile Routing Research Challenge dataset used in our computational experiments. 

## Folder Contents
* Original Instance: RouteID_2b8df66d-fcd4-438e-931c-3b84b36a5c6b
* Derived Instances: The folder includes instances I1 through I6, which have been generated to consider different time window configurations.

## Time Window Regimes
The derived instances are classified according to their specific time window regime. The abbreviations used in the file names denote the following:
* W  : Wide-window regime
* SB : Single-bottleneck regime
* DP : Distributed-pressure regime
